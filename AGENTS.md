# krci-security-operator - AI Agent Guide

A Go operator (controller-runtime) for the security integrations of a KubeRocketCI cluster, one module per integration. The first module imports Trivy Operator reports (`VulnerabilityReport`, `ExposedSecretReport`) into the cluster's DefectDojo. One instance runs per cluster with cluster-wide read-only access. The repository defines no CRDs, `api/` types or webhooks. See `docs/trivy.md` for the behavior and the DefectDojo naming table.

## Project Structure

```
cmd/main.go                          Manager entry (flags, metrics, health probes, leader election, module registration)
internal/controller/trivy/           Trivy module: config.go (env, validation), trivy.go (builder, watches), reconciler.go (pass, imports),
                                     classify.go (scope of a namespace), closing.go (closing, sweeper that wakes namespaces), watch.go (event mapping)
pkg/defectdojo/                      DefectDojo API v2 client (reimport-scan, per-test lock)
pkg/trivy/                           Report parsing, image and workload resolution, naming per scope, component tag, ownership; testdata/
deploy-templates/                    Hand-maintained Helm chart (the only deployment artifact)
deploy-templates/README.md           Generated by `make helm-docs` from README.md.gotmpl (DO NOT EDIT)
docs/                                Hand-written docs
ct-configs/                          chart-testing (ct) lint config for the Helm chart
test/deploy/                         Chart render tests (helm template; skipped without helm)
.github/workflows/                   pr and release workflows
Makefile                             Build/test/lint commands
```

## Critical Rules

### Never Edit These (Generated)

- `deploy-templates/README.md` - from `make helm-docs` (edit `README.md.gotmpl` and the `# --` comments in `values.yaml` instead)
- `CHANGELOG.md` - from `make changelog`

CI runs `make validate-docs`; it fails when `deploy-templates/README.md` is stale.

### RBAC Is Hand-Maintained

The ClusterRole is read-only and lists exactly the verbs the code calls. It lives in `deploy-templates/templates/role.yaml`; keep it and the access table of `docs/trivy.md` identical. `test/deploy` fails on a write verb in the ClusterRole. There are no RBAC markers. A new read through the API reader needs its verb added.

### No Dependency on Other KubeRocketCI Operators

`Stage` and `CodebaseImageStream` (`v2.edp.epam.com`) are read as unstructured objects or small local structs. Do not import the cd-pipeline-operator or codebase-operator modules.

### Configuration Is Environment Variables

The chart maps values to the variables parsed in `internal/controller/trivy/config.go`. A new value needs: the variable in `config.go` with a test, the env entry in `deploy-templates/templates/deployment.yaml`, its name in `envNames` of `test/deploy/render_test.go`, the `# --` documented key in `values.yaml`, `make helm-docs`, and the configuration table of `docs/trivy.md`. The render tests fail when the chart and `config.go` disagree on a variable or a default.

## Design Notes

- **Reconcile key is a namespace.** Namespaces are classified on every pass (`classify.go`): stage when an in-cluster Stage with DNS label names points at it and its tenant label equals the Stage namespace, else tenant when it has the tenant label, else platform. The tenant is the namespace label `app.edp.epam.com/tenant`, never what a Stage claims. `excludeNamespaces` globs and disabled scopes make a namespace out of scope.
- **Cache discipline.** Only Namespaces, Stages and the metadata of reports are watched. Full reports, workloads, `CodebaseImageStream`s and the Secret are read through `mgr.GetAPIReader()`; never read a report through the cache.
- **Naming per scope** is built in `pkg/trivy.ReportImport` from a `Target`; see the table in `docs/trivy.md`.
- **Ownership.** The operator closes only DefectDojo tests that carry its `krci-cluster:<clusterName>` tag and a `krci-scope` of `runtime`, `tenant` or `platform` (`trivy.IsOwned`).
- **Closing.** After a pass the owned tests of the namespace that the pass did not import are closed; a namespace that is gone or out of scope is released once; the sweeper repeats this for every owned test at start and every 6h.
- **State is in memory.** A restart re-imports once.
- **Failures never crash the manager.** A transient failure is returned from `Reconcile` so the workqueue backs off and the error metric counts it. Only an absent optional dependency (credentials Secret missing or without `url`/`token`, report CRD not served) returns a nil error with `RequeueAfter`.
- **The sweeper never closes.** `sweep` only wakes namespaces through `Reconciler.wake` (a `source.Channel` of the controller); `Reconcile` releases and closes, so one namespace is never closed and imported in parallel.
- **Memory.** Reports are listed in pages of `reportsPageSize` and imported page by page; never accumulate full reports across pages.
- **State is bounded.** `closed`, `healed` and `released` are pruned after each pass, on release and by the sweeper.
- **API load.** Report watches use `ResourceVersionChangedPredicate`, the periodic requeue is jittered, and the credentials Secret is cached for a minute.
- **CRD discovery is at start** (`isServed`); a CRD installed later needs a restart.

### Logging

Follow Kubernetes logging message style guidelines: start with a capital letter, no trailing period, active voice and past tense (`"Could not import report"`), name the object type, balanced key-value pairs.

**Reference:** <https://github.com/kubernetes/community/blob/master/contributors/devel/sig-instrumentation/logging.md#message-style-guidelines>
